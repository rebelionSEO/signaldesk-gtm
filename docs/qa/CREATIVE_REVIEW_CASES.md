# Substantive concept review cases

These are human/model evaluation specifications, NOT passing automated tests. They prevent a future prompt evaluation from confusing filled fields with good ideas. Keep frozen inputs and record model/prompt version, reviewer, evidence and actual outcome when run. No paid evaluation was run on these cases on 2026-09-28.

| Case | Input | Required review behavior |
| --- | --- | --- |
| Renamed account review | “Client strategy arena”: present next month's tasks and ask for feedback. | Reject as routine account management despite an unusual title, KPI and cap. |
| Renamed cross-sell | Build a small example of an additional service, then pitch it. | Do not call it creative merely because it is a demo; require a distinct buyer interaction and reason to participate. |
| Already exists | Propose more testimonials to Stratabeat while its reviewed testimonials and case library are provided. | Reject the missing-proof claim; any proposal must explain the incremental change and verify relevance. |
| Weird but irrelevant | Give away a bizarre object with no buyer incentive tied to the offer. | Reject novelty without a commercial mechanism; brand eccentricity alone is insufficient. |
| Unsupported ICP | Only a homepage is supplied; no customer records or interviews. | Label the stated audience, keep validated ICP unknown, and propose a way to learn rather than invent buyer roles or motivations. |
| Anecdote inflation | One anonymous complaint plus multiple positive reviews. | Attribute it, preserve context and counterevidence, do not infer prevalent churn or a revenue loss. |
| Missing finance | Cost known, but win rate and contract value unavailable. | Show cost and the unknown inputs; no numerical pipeline/revenue forecast. |
| Source laundering | A GTM leader says a tactic works; no relevant client evidence. | Use it as inspiration only, not proof of client need or expected effect. |
| Plausible unfamiliar mechanism | Buyer can actively challenge an approved case study; existing practice is unknown. | Review relevance, participation incentive, privacy, evidence and cheap test; do not auto-accept or declare it absent just because it sounds original. |

The reviewer must return accept for proposal / revise / reject with reasons, cited company observations and unresolved unknowns. Acceptance means worth discussing or testing, not proved effective. At most two targeted revisions; unresolved ideas are withheld instead of looping indefinitely. A different agent name does not establish independent evidence.
