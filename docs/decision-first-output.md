# Decision-first output

The user-facing deliverable is a GTM decision dashboard, not a crawl report.

- Overview: short finding, relevant sources, proposed first test and a compact experiment comparison.
- Ideas: at most five distinct commercial tests, with channel, existing work, incremental change, assumption, outcome measure, budget basis and stop rule.
- Evidence: sources supporting each recommendation; technical coverage appears only in an optional method disclosure.
- Crawl inventories, raw bodies and token accounting are research inputs. Do not open a separate crawl report as the primary deliverable unless requested.
- Reuse saved research before making paid calls. A Screaming Frog export can be a discovery input, but URLs alone are not proof of page contents. Import support is not implemented yet.
- Public evidence can support proposed experiments, not claims of funnel failure, causal lift or internal performance. State what must be confirmed before launch.

The updated Stratabeat example combines saved model page reviews and assistant-reviewed external sources. It remains an example scenario, not a completed autonomous run. Required coverage and execution gates remain in place; the live runner still needs recovery for incomplete pages before it can finish. No paid API calls were made during this presentation revision.
